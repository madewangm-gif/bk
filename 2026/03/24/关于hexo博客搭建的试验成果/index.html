2026-03-24

这个错误的核心意思是：你的 Hexo 主题 simpleblock 依赖一个叫 jade 的模块，但你的项目中没有安装这个模块，导致 Hexo 在加载主题脚本 helpers.js 时失败了。

jade 是一个 Node.js 的模板引擎（现在改名为 pug），你的主题代码里明确引用了它，但它并没有被安装到你的项目依赖中，所以 Node.js 找不到这个模块就报错了。

解决方案

你只需要在项目根目录下安装缺失的 jade 模块即可，具体步骤如下：

1. 打开终端，确保在 Hexo 项目根目录

总结

  1. 核心问题：Hexo 主题依赖的 jade 模块未安装，导致脚本加载失败。
  2. 解决方案：通过 npm install jade --save 安装缺失的模块即可解决。
  3. 备选方案：若 jade 兼容性有问题，可替换为新版 pug 并修改主题引用代码。
